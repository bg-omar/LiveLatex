## 0.0.10

Thank you for supporting LiveLatex — a few upgrades so writing stays closer to the editor 🎉

### New 💪
- **LaTeX Preview** toggle (**Ctrl+Alt+P**) and a tidier editor menu
- Wider sections combo with indent + level filters
- Simpler **Generate Table** wizard
- TikZ: toolbar extras, `\resizebox` export, **Load Last**, help overlay, undo/redo
- `\url{...}` links in the HTML preview

### Fixed 🪲
- **Insert Reference** no longer freezes the UI
- Preview no longer auto-scrolls the editor

### Tidying 👌
- **Refresh** clears the document cache (duplicate Options entry removed)
